# AI Response Quality Evaluation

## Project Overview

This project demonstrates a structured approach to evaluating AI-generated responses based on quality criteria.

The goal is to compare two responses to the same user prompt and identify which one provides the best overall answer.

## Evaluation Criteria

The responses are assessed using five criteria:

1. **Accuracy:** Is the information factually correct?
2. **Relevance:** Does the response address the user's request?
3. **Clarity:** Is the information easy to understand?
4. **Instruction Following:** Does the response follow the user's instructions?
5. **Completeness:** Does the response provide all the necessary information?

## Methodology

Each response is evaluated independently using a score from 1 to 5 for each criterion.

The scores are supported by written justifications.
